ДЕМО-ДАНІ RAW STUDIO — приклади записів для швидкої перевірки
══════════════════════════════════════════════════════════════════
Файли згенеровано самим RAW Studio (Генератор): fs = 12 ГГц,
8 каналів, uint16 LE, інтерлівінг по відліках, DC 32768.

ЯК ВІДКРИВАТИ
─────────────
1. Запустіть RAW Studio (RAW_Studio.bat).
2. «📂 Відкрити файл» → файл із цієї папки.
3. fs = 12e9 (12 ГГц), канали = 8 — дефолти вже правильні.
4. «Спектр» — піки тонів; «Блоки (64 МГц)» — засвічені канали;
   «Статистика» — DC/RMS без кліпу (min>>0, max<<65535).

  ch0: 260.00 МГц → блок 1, канал у блоці 3 (глобальний 3)
  ch1: 852.00 МГц → блок 2, канал у блоці 6 (глобальний 13)
  ch2: 1540.00 МГц → блок 2, канал у блоці 17 (глобальний 24)
  ch3: 2355.20 МГц → блок 3, канал у блоці 19 (глобальний 45)
  ch4: 3148.80 МГц → блок 4, канал у блоці 12 (глобальний 59)
  ch5: 4147.20 МГц → блок 5, канал у блоці 12 (глобальний 78)
  ch6: 5222.40 МГц → блок 6, канал у блоці 13 (глобальний 98)
  ch7: шум (нема тону)

demo_pulse_8ch.raw — імпульсна гребінка:
  ch0: імпульси з частотою слідкування 380 МГц, ширина 1 нс →
       гармоніки кожні 380 МГц: 380, 760, …, 5700 МГц
       (знайдено 15 з 15 очікуваних) — гребінка засвічує канали
       у всіх 6 блоках одразу; ch1…ch7 — тільки шум.

Обидва файли по 4,8 МБ (300 000 відліків × 8 каналів × 2 байти).
